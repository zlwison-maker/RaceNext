# First5 Pilot Recommendation

Last Updated: 2026-07-31

## 1. Selection Logic

First5 不简单选择最高分。

本次选择不追求赛事类型平均覆盖，而是优先验证 RaceNext 的核心价值：

- 至少 2-3 个高决策复杂度越野赛事。
- 至少 1 个大众搜索量高的赛事。
- 优先选择住宿、交通、装备、训练计划、赛事周边具备自然商业闭环的赛事。
- 不因为数据容易获取而选择赛事。

当前仍不代表上线名单。进入下一阶段前，需要人工复核官方来源和 P0 / P1 字段。
