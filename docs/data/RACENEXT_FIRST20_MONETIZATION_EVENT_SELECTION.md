Version: 1.0
Status: Active MVP V2 planning spec
Last Updated: 2026-07-31

# 1. Selection Goal

First20 Monetization Events 是 RaceNext MVP V2 的第一批商业化赛事筛选标准。

它们不是：

- Top20 赛事。
- 最复杂赛事。
- 最能体现 AI 能力的赛事。
- 最适合做长期赛事决策内容的赛事。

它们是：

> 最可能产生 SEO 流量、用户点击和商业转化的赛事。

MVP V2 当前目标：

> 3 个月内验证商业闭环，实现月收入 5000 元。

因此，本阶段赛事选择优先回答：

- 用户是否会搜索这场赛事？
- 用户是否已经有报名或参赛准备意图？
- 用户是否需要住宿、交通、装备、保险或旅行服务？
- RaceNext 是否能自然承接这些需求并产生联盟收入？

当前阶段不优先回答：

- 这场赛事是否最适合做 AI 决策？
- 这场赛事是否最能体现复杂适合人群分析？
- 这场赛事是否最容易生产长篇内容？

# 2. Scoring Model

总分 100。

| Dimension | Weight | MVP Meaning |
|---|---:|---|
| Search Demand 搜索需求 | 40 | 流量核心 |
| Commercial Potential 商业消费潜力 | 30 | 收入核心 |
| Event Popularity 用户关注度 | 20 | 参赛意愿和信任基础 |
| Data Availability 数据可获取性 | 10 | 上线可行性 |

## 2.1 Search Demand 搜索需求 - 40 分

评估：

- 百度搜索价值。
- 微信搜索价值。
- 小红书讨论热度。
- 用户主动搜索意图。
- 是否存在“赛事名称 + 报名 / 抽签 / 住宿 / 交通 / 装备 / 保险 / 攻略”等组合词。

说明：

> Search Demand 是 MVP 流量核心。

高分赛事通常具备：

- 赛事名称稳定且容易搜索。
- 报名、抽签、比赛日等节点会带来周期性搜索峰值。
- 城市或目的地本身有搜索热度。
- 用户会在微信、百度、小红书中主动找参赛信息。

评分参考：

- 36-40：全国顶级搜索需求，赛事名本身就是高频关键词。
- 30-35：区域强势或圈层强势，能形成稳定搜索。
- 20-29：有一定搜索，但需要内容分发放大。
- <20：搜索需求不足，不适合第一批。

## 2.2 Commercial Potential 商业消费潜力 - 30 分

评估用户是否存在：

- 住宿需求。
- 交通需求。
- 装备需求。
- 保险需求。
- 周边旅行需求。

说明：

> Commercial Potential 是 MVP 收入核心。

高分赛事通常具备：

- 外地参赛比例高。
- 城市酒店需求明显。
- 到达比赛地有交通决策成本。
- 越野、高海拔、长距离或夜间赛事带来装备和保险需求。
- 目的地有旅行、景区或家庭同行消费空间。

评分参考：

- 27-30：住宿、交通、装备、保险、旅行中至少 4 类强需求。
- 22-26：住宿和交通强，装备或保险中至少 1 类成立。
- 16-21：主要只有住宿和交通。
- <16：商业入口弱，不适合第一批。

## 2.3 Event Popularity 用户关注度 - 20 分

评估：

- 赛事知名度。
- 参赛人数。
- 跑者认可度。
- 社区讨论度。
- 是否有历史口碑或品牌背书。

说明：

用户关注度不等于搜索需求，但会影响页面信任和点击转化。

高分赛事通常具备：

- 全国跑者熟悉。
- 报名竞争明显。
- 有长期举办历史。
- 有大型赛事认证、国际标牌、UTMB / ITRA 等圈层背书，或在跑者社区中有强品牌心智。

## 2.4 Data Availability 数据可获取性 - 10 分

评估：

- 官方信息是否完善。
- 报名信息是否容易获取。
- 组别、日期、地点、起终点是否清晰。
- 商业服务是否容易人工整理。
- 是否能快速产出 P0 页面信息。

说明：

数据可获取性是上线门槛，但不是选择赛事的主要理由。

不能因为一场赛事“好写、好整理”就进入 First20。

# 3. Marathon vs Trail Analysis

MVP V2 不应该只做越野。

原因：

> 当前目标是 3 个月商业闭环，不是证明 RaceNext 能处理最复杂赛事决策。

## 3.1 Comparison

| Dimension | 大众马拉松 | 热门越野 |
|---|---|---|
| 搜索流量 | 更高，赛事名和报名节点搜索明显 | 圈层集中，搜索量通常小于顶级马拉松 |
| 商业价值 | 酒店、交通、旅行强，装备和保险中等 | 装备、保险、住宿、交通都强，客单价潜力高 |
| 用户消费能力 | 大众规模大，消费分层明显 | 圈层消费能力强，装备和旅行意愿高 |
| SEO 机会 | 竞争更强，但关键词量大 | 长尾关键词好切入，例如强制装备、交通接驳 |
| 数据获取难度 | 官方信息、媒体报道、报名信息通常更容易获取 | 赛道、装备、关门、接驳信息更复杂，但商业信息更有价值 |
| 转化路径 | 报名 -> 酒店/交通 -> 旅行/装备 | 报名 -> 装备/保险 -> 住宿/交通/接驳 |
| MVP 风险 | 竞争大，页面差异化需要服务模块支撑 | 流量天花板较低，不能单独支撑 MVP 收入假设 |

## 3.2 Recommendation

First20 应采用混合结构：

- 约 60% 大众马拉松。
- 约 40% 热门越野。

建议首批结构：

- 12 场大众马拉松 / 半程马拉松。
- 8 场热门越野 / 山地越野。

这样既能用马拉松验证搜索流量和住宿交通点击，也能用越野验证装备、保险和高客单价消费。

马拉松负责：

- 大流量。
- 报名搜索。
- 酒店和交通转化。
- 微信搜索和公众号承接。

越野负责：

- 高消费意愿。
- 装备和保险转化。
- 住宿、接驳和旅行服务。
- RaceNext 的差异化服务感。

# 6. First5 MVP Validation Events

First5 的目标不是覆盖最多赛事类型，而是最快验证：

- 流量
- 点击
- 商业转化

推荐 First5：

## 1. 上海马拉松

选择原因：

- 搜索需求极强。
- 报名、抽签、酒店、交通关键词明确。
- 城市酒店和交通服务成熟，联盟入口容易配置。
- 适合验证大众马拉松流量转化。

优先验证：

- 报名入口点击。
- 酒店区域点击。
- 城市交通点击。

## 2. 北京马拉松

选择原因：

- 国内头部赛事心智极强。
- “北马报名 / 北马抽签 / 北马住宿”搜索意图稳定。
- 外地参赛用户住宿交通需求明显。

优先验证：

- 搜索流量承接。
- 报名和抽签相关 FAQ。
- 酒店和交通点击。

## 3. 厦门马拉松

选择原因：

- 高知名度赛事，目的地消费明显。
- 酒店、交通、旅行天然适配商业转化。
- 适合验证“赛事 + 旅游城市”的服务页价值。

优先验证：

- 酒店点击。
- 旅行服务点击。
- 交通入口点击。

## 4. 崇礼168超级越野赛

选择原因：

- 越野圈层高关注赛事。
- 住宿、交通、接驳、装备、保险需求都强。
- 官方信息相对丰富，便于验证越野服务模块。

优先验证：

- 装备点击。
- 保险点击。
- 接驳 / 交通点击。
- 住宿区域点击。

## 5. 香港100越野赛 HK100

选择原因：

- 亚洲知名越野赛，对中国大陆跑者有较强吸引力。
- 跨境参赛带来住宿、交通、保险和行程规划需求。
- 官方页面包含交通、住宿、装备等服务信息入口，适合验证 RaceNext 的服务聚合价值。

优先验证：

- 跨境交通点击。
- 酒店点击。
- 装备和保险点击。

# 8. Explicitly Out Of Scope

MVP 阶段暂不因为以下因素选择赛事：

- 决策复杂度最高。
- AI 内容空间最大。
- 最容易写内容。
- 最适合做适合人群分析。
- 最适合训练建议。
- 最容易形成完整长文攻略。

避免回到 Decision Layer 思路。

First20 Monetization Events 只服务当前 MVP V2 目标：

```text
搜索流量
↓
赛事服务需求
↓
商业点击
↓
联盟收入
```
