# RaceNext MVP Event Selection

Version: 1.0
Status: Active proposal
Last Updated: 2026-07-31

---

# 1. Selection Goal

MVP V2 赛事选择目标：

> 寻找最容易产生商业收入的赛事。

当前阶段不再以 First50 Decision Events 作为首批目标。

MVP V2 首批目标是：

> First20 Monetization Events。

这些赛事必须能够同时承接：

- 高搜索热度
- 高参赛意愿
- 高消费需求

RaceNext 需要优先服务已经明确想参加热门赛事的用户，并通过报名、住宿、交通、装备、保险和旅行服务形成商业闭环。

---

# 2. What Changes From First50

旧方向：

> First50 Decision Events。

核心问题：

> 这场比赛是否值得跑、是否适合我？

新方向：

> First20 Monetization Events。

核心问题：

> 我已经决定跑这个比赛，接下来怎么报名、怎么去、住哪里、买什么、要不要保险？

因此，赛事筛选不再优先选择“决策复杂度最高”的赛事，而是优先选择“最容易带来商业转化”的赛事。

---

# 3. Scoring Model

总分 100。

| Dimension | Weight |
|---|---:|
| Search Demand | 35 |
| 商业消费潜力 | 30 |
| 赛事热度 | 20 |
| 数据可获取性 | 10 |
| 内容生产成本 | 5 |

## 3.1 Search Demand - 35%

衡量用户是否会主动搜索该赛事及相关服务。

重点观察：

- 赛事名称是否明确、稳定、可搜索。
- 是否有明显“赛事名称 + 报名”需求。
- 是否有“赛事名称 + 住宿 / 酒店 / 交通 / 装备 / 保险 / 攻略”扩展搜索空间。
- 是否适合百度、微信搜索、搜狗、360 等中国大陆搜索场景。
- 是否适合公众号文章承接和复访。

高分赛事通常具备：

- 大众知名度高。
- 报名窗口、抽签、比赛日等节点明确。
- 搜索词不容易被无关内容淹没。

Google Search 不作为本维度核心判断依据。

## 3.2 商业消费潜力 - 30%

衡量用户围绕该赛事发生消费的可能性和金额。

重点观察：

- 是否有明显住宿需求。
- 是否有明显交通需求。
- 是否有装备购买需求。
- 是否适合保险推荐。
- 是否存在周边旅行、景点、餐饮、本地服务需求。
- 是否适合联盟佣金模式。

高分赛事通常具备：

- 外地参赛比例高。
- 举办地需要跨城交通。
- 起终点或领物点周边住宿选择复杂。
- 越野、长距离、高海拔或特殊天气带来装备和保险需求。
- 文旅属性强，用户可能顺路旅行。

## 3.3 赛事热度 - 20%

衡量赛事本身的关注度和参赛意愿。

重点观察：

- 赛事品牌知名度。
- 报名竞争程度。
- 社群讨论度。
- 历史口碑。
- 是否具有城市或目的地吸引力。
- 是否处于报名、抽签、公布路线、赛前准备等关键时间窗口。

高分赛事不一定是最难赛事，但一定要有真实跑者关注。

## 3.4 数据可获取性 - 10%

衡量是否能用合理成本获得和维护关键信息。

重点观察：

- 官方信息是否可访问。
- 报名入口是否清晰。
- 日期、地点、组别是否明确。
- 交通住宿区域是否可人工整理。
- 装备、保险、旅行信息是否能基于公开事实和服务平台维护。

数据可获取性是门槛，不是主要加分项。

不能因为数据容易获取而选择低商业价值赛事。

## 3.5 内容生产成本 - 5%

衡量页面内容是否能低成本生产和更新。

重点观察：

- 是否需要大量人工考证。
- 是否存在频繁变化的信息。
- 是否需要复杂实时数据。
- 是否能通过模板化方式生产住宿、交通、装备、保险模块。

该维度权重最低。

MVP V2 可以接受为高价值赛事付出一定人工成本。

# 4. First20 Monetization Events Criteria

First20 Monetization Events 必须优先满足以下标准：

1. 中国大陆用户搜索热度高。

2. 用户参赛意愿强。

3. 存在明显消费需求，包括：

- 住宿需求
- 交通需求
- 装备需求
- 保险需求

4. 适合 SEO。

5. 适合微信搜索和公众号承接。

6. 有明确报名信息或可验证报名来源。

7. 页面能自然放置商业服务入口。

---

# 5. Event Types To Prioritize

优先类型：

- 热门城市马拉松。
- 抽签或报名竞争明显的马拉松。
- 文旅属性强的马拉松。
- 外地参赛比例高的越野赛。
- 长距离越野赛。
- 高海拔、山地、景区型赛事。
- 交通复杂、住宿选择有限的赛事。

谨慎选择：

- 低搜索量小型本地赛。
- 纯线上赛。
- 只卖奖牌或套餐的活动。
- 与跑步关联弱的徒步、亲子、障碍娱乐活动。
- 无法确认报名信息且短期无法补齐的赛事。

---

# 6. Publish Gate For MVP V2

First20 Monetization Events 上线前至少应具备：

- 赛事名称
- 比赛日期或明确月份
- 举办城市和具体区域
- 至少一个参赛组别
- 报名状态
- 报名入口或可信来源说明
- 至少 2 个商业服务模块
- 至少 1 个可追踪联盟链接
- 适合“赛事名称 + 报名 / 住宿 / 交通 / 装备 / 保险”的页面标题和内容结构

推荐优先补齐：

- 起点 / 终点 / 领物地点
- 推荐住宿区域
- 交通枢纽到比赛地距离
- 必备装备
- 推荐保险类型
- 周边旅行入口

---

# 7. Suggested Workflow

1. 从热门赛事、报名节点赛事和高消费需求赛事中建立候选池。

2. 按 MVP V2 评分模型打分。

3. 选择 First20 Monetization Events。

4. 为每场赛事补齐报名、住宿、交通、装备、保险中的高转化数据。

5. 每场赛事至少配置 2-3 个商业模块。

6. 上线后每周复盘：

- 搜索曝光
- 页面访问
- 报名入口点击
- 酒店点击
- 交通点击
- 装备点击
- 保险点击
- 联盟收入

7. 根据收入和点击数据调整下一批赛事选择。

# 8. Relationship With Existing Documents

`FIRST50_SELECTION.md` 仍可作为长期 Decision Events 的方法论参考。

但 MVP V2 开发和运营优先遵循本文：

> `RACENEXT_MVP_EVENT_SELECTION.md`

当前阶段：

- First20 Monetization Events 优先于 First50 Decision Events。
- Monetization Layer 优先于 Decision Content。
- 商业转化数据优先于 AI 决策内容。

当 MVP V2 验证收入闭环后，再恢复和升级 First50 Decision Events。
