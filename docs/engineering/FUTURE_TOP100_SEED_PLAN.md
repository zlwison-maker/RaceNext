# Future Top100 Seed Plan

## 背景

当前 `data/merged/merged_sample.json` 是 Connector POC 样本，用来验证 RunChina / Zuicool 等来源的采集、归一化和合并链路。

它不能作为正式 Top100 赛事数据库，原因包括：

- 样本中包含已结束赛事。
- 部分赛事日期、报名状态、报名链接不完整。
- 数据覆盖是 Connector 验证导向，不是用户决策导向。
- 样本数量、地域、赛事类型和未来有效性都不稳定。

## 目标

下一阶段应建立 `future_top100_seed.json`，作为 RaceNext MVP 的未来赛事池。

这个文件只收录对跑者有当前决策价值的未来赛事，用于支撑：

- 首页赛事日历
- 赛事推荐
- 后续 Top100 数据补全
- 后续人工审核和自动同步

## 收录原则

`future_top100_seed.json` 只收录：

- 未来确定举办的赛事
- 或报名中 / 即将开放 / 抽签中的赛事
- 有明确城市、日期、距离或报名入口的赛事优先

默认不收录：

- 已结束赛事
- 已取消赛事
- 只有来源页但缺少关键决策字段的赛事
- 无法判断是否仍有报名价值的历史赛事

## 字段优先级

第一阶段建议字段：

| 字段 | 说明 |
| --- | --- |
| `name` | 赛事名称 |
| `raceDate` | 比赛日期 |
| `city` | 城市 |
| `province` | 省份 / 地区 |
| `type` | 赛事类型 |
| `distance` | 主要距离或组别距离 |
| `registrationStatus` | 报名状态 |
| `registrationUrl` | 报名链接 |
| `sourceUrl` | 来源链接 |

第二阶段可补充：

- 费用
- 累计爬升
- 组别列表
- 报名开始 / 截止时间
- 官网链接
- 交通便利度
- 新手友好判断
- 赛事特色标签

## 当前 MVP 展示策略

在正式 seed 建立前，页面对 Connector POC 样本做展示层过滤：

- 默认隐藏已结束赛事。
- 默认隐藏已截止赛事。
- 默认展示未来赛事。
- 无日期赛事只有在报名中 / 即将开放 / 抽签中时展示。
- 推荐列表不使用已结束赛事。
- 卡片标签只保留少量高价值决策标签。

## 后续步骤

1. 建立 `future_top100_seed.json` 初版。
2. 从 Connector POC 样本中筛出未来有效赛事。
3. 人工补齐重点赛事的日期、城市、距离、报名状态和报名链接。
4. 增加 seed 校验脚本，确保不会混入已结束赛事。
5. 再逐步接入 Connector 自动更新，但保留人工审核入口。
