# 下一场推荐逻辑说明

## 1. 推荐页目标

「赛事推荐」不是赛事筛选器，而是轻量赛事顾问。

MVP 阶段通过结构化输入判断跑者的目标、经验、能力区间和出行范围，再用规则推荐更适合的下一场比赛。当前阶段不接 AI API，不使用自由文本输入，也不依赖登录、数据库或用户历史。

推荐分两层设计：

- 轻量推荐：用户 10 秒内完成输入，立即得到规则推荐。
- 精准推荐：未来可增加训练量、伤病、预算、交通、装备和 AI 解释能力。

## 2. RunnerProfile 字段说明

RunnerProfile 定义在 `types/runner.ts`。

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `regionPreference` | 目标参赛地区 | 华东、华南、华北、华中、西南、西北、东北、港澳台、全国、海外 |
| `targetRaceType` | 目标赛事类型 | 马拉松、越野、UTMB |
| `targetDistance` | 目标距离 | 10KM、半马、全马、30KM、50KM、100KM |
| `longestCompletedRace` | 已完成最远比赛 | 用于推断基础能力区间 |
| `runnerExperience` | 跑步经验 | 新手、有一定基础、进阶、高阶、精英 |
| `halfMarathonPB` | 半马 PB | 本轮只用于推荐理由提示 |
| `marathonPB` | 全马 PB | 本轮只用于推荐理由提示 |
| `isFirstTrail` | 是否首次越野 | 用于限制高难度越野推荐 |
| `travelScope` | 是否接受外地参赛 | 只看本地区、全国都可以、海外也可以 |

## 3. 赛事推荐规则

### 赛事类型强匹配

- 目标为越野：只推荐 `trail`、`ultra_trail`、`utmb`。
- 目标为马拉松：优先推荐 `marathon`，可次级推荐 `half_marathon`、`road_running`，不推荐越野。
- 目标为 UTMB：只推荐 `utmb`、`ultra_trail`。

### 距离匹配

赛事组别距离越接近目标距离，分数越高：

- 误差 1KM 以内：高分
- 误差 10KM 以内：中高分
- 误差 25KM 以内：低分
- 更远：不加分

### 首次越野规则

如果 `isFirstTrail = true`：

- 优先推荐新手友好组别。
- 优先推荐 L5 及以下难度。
- 不推荐 L8-L10。
- 推荐理由中提示更适合作为入门越野选择。

### 地区与出行范围

- `local_region`：只推荐目标地区匹配的赛事。
- `nationwide`：允许国内赛事。
- `overseas`：允许国内和海外赛事。

## 4. 能力区间推断

基础能力区间由「已完成最远比赛」推断，再根据跑步经验微调。

| 已完成最远比赛 | 推荐难度区间 |
| --- | --- |
| 未参赛 / 5KM / 10KM | L1-L3 |
| 半马 | L3-L5 |
| 全马 | L4-L6 |
| 20KM 越野 | L4-L5 |
| 30KM 越野 | L5-L7 |
| 50KM 越野 | L7-L8 |
| 100KM 越野 | L9-L10 |

跑步经验会轻微调整能力区间：

- 新手：降低 1 级
- 有一定基础 / 进阶跑者：不调整
- 高阶跑者：提高 1 级
- 精英跑者：提高 2 级

## 5. 匹配度计算方式

匹配度由五部分组成，满分 100：

| 维度 | 最高分 |
| --- | --- |
| 赛事类型 | 25 |
| 目标距离 | 20 |
| 能力匹配 | 30 |
| 地区匹配 | 15 |
| 标签与 PB 提示 | 10 |

最终分数会限制在 0-100，并按目标类型优先级和分数排序。

## 6. 风险提示生成规则

风险提示基于当前赛事组别和 RunnerProfile 生成：

- 如果赛事难度高于当前能力区间：提示作为挑战目标，并提前准备专项训练。
- 如果首次越野且难度大于等于 L5：提示准备爬升、下坡、补给和装备。
- 如果组别不是新手友好：提示不适合作为完全新手第一场比赛。
- 如果目标距离大于等于 50KM：提示确认耐力、补给和恢复能力。
- 如果没有明显风险：提示结合近期训练量、伤病情况和官网关门时间再决定。

## 7. 未来 AI 推荐扩展方向

后续可以在不改变赛事数据模型的前提下扩展精准推荐：

- 增加训练量、周跑量、爬升训练、伤病状态和可出行时间。
- 增加预算、交通、住宿、补给、装备等决策维度。
- 引入 AI 对推荐结果进行自然语言解释，但底层规则仍保留为可审计基础。
- 结合用户收藏、点击和报名意向，形成个人化推荐。
