RaceNext 赛事详情页内容撰写规范 V1

一、内容目标
RaceNext 的赛事详情页不是赛事百科，也不是传统攻略页。
核心目标只有一个：
帮助用户判断：这场比赛到底是什么体验，值不值得去，适不适合自己。

因此所有内容都必须服务于“赛事决策”。
不是为了填充页面。
不是为了 SEO 增加字数。
不是为了显得内容很多。
RaceNext 内容的价值来自：
真实信息 + 真实跑者反馈 + RaceNext 判断
最终帮助用户完成：
认识比赛 → 理解特点 → 判断适配 → 做出参赛决策

二、内容真实性硬规则
这是所有赛事内容必须遵守的最高原则。
RaceNext 的内容严格分为三层。
1. Official / Event Facts
指可验证的赛事事实，例如：
- 比赛日期
- 比赛地点
- 起终点
- 赛事组别
- 距离
- 爬升
- 路线
- 报名时间
- 报名资格
- 关门时间
- 补给点
- 强制装备
- 官方赛事规则
这些内容必须来自：
- 赛事官方
- 主办方
- 官方公众号
- 官方报名页面
- 官方赛事手册
- 可信官方媒体信息
原则：
没有确认，就不写死。

禁止根据往届赛事自行推断当年规则。
例如：
错误：
2027 厦门马起点位于会展中心。

如果 2027 官方尚未公布，则不能写成事实。
可以写：
具体起终点以赛事官方最终公布为准。

2. Real Media / Runner Feedback
指真实存在的：
- 跑者赛记
- 完赛复盘
- 社区讨论
- 媒体赛事报道
- 视频体验
- 多位参赛者反复提到的体验
RaceNext 可以：
- 搜集
- 摘要
- 聚合
- 归纳
- 重组
- 优化语言
但绝对不能：
- 编造跑者体验
- 编造媒体评价
- 编造“大家都这么认为”
- 把一个人的感受写成普遍结论
- 为了让文章更生动而补剧情
核心原则：
可以组织真实反馈，但不能创造真实反馈。

当多个来源反复出现类似观点时，可以写：
不少跑者会提到……

多篇赛记里反复出现……

跑者反馈中经常被提到……

如果只是个别观点，应写得更谨慎：
有跑者提到……

而不是：
跑者普遍认为……

3. RaceNext Judgment
RaceNext 可以基于：
官方事实 + 跑者真实反馈
形成自己的赛事判断。
例如：
- 这场比赛更适合哪类跑者
- 是否适合 PB
- 最大吸引力是什么
- 真正难点是什么
- 值不值得专程去
- 更像“比赛”还是“旅行”
- 第一次参加需要注意什么
但必须让用户清楚：
这是 RaceNext 的编辑判断。

不能伪装成：
- 官方结论
- 媒体原话
- 跑者共识
推荐表达：
RaceNext 更愿意把它理解成……

在我们看来……

基于这些跑者反馈，RaceNext 的判断是……

如果你更在意 XXX，这场比赛值得放进候选清单。

三、核心内容原则
所有赛事内容遵循一句话：
事实写事实，评价写评价，RaceNext 判断明确写成判断。

如果证据不足：
宁可不写，也不要猜。
RaceNext 不需要表现得“什么都知道”。
可信度比完整度重要。

四、Race Guide 标准内容结构
每场赛事的 Race Guide 固定由四部分构成。
A. Opening｜赛事印象
回答：
这场比赛给人的核心感受是什么？

Opening 不是赛事介绍。
不要从：
XX 马拉松创办于……

开始。
而是尽快帮助用户感受到这场赛事的“人格”。
内容应来自：
- 真实赛道环境
- 跑者高频记忆点
- 比赛氛围
- 城市 / 山地特征
- 特别有辨识度的体验
例如厦门马：
不是：
厦门马拉松是一项在厦门举行的大型城市马拉松赛事。

而是：
很多人记住厦马，不一定只是因为成绩。有人记住的是演武大桥上的海景，有人记住的是环岛路一路伴着自己的海风……

Opening 撰写规范
建议：
- 2–3 个自然段
- 每段 2–3 句话
- 不一句一段
- 不人为换行
- 不连续制造“金句”
- 有温度，但不过度抒情
- 真实体验优先于形容词
目标：
用户读完 Opening，就能说出这场比赛最鲜明的感觉。

五、RaceNext Judgment｜RaceNext 怎么看这场比赛
这是整个 Race Guide 最重要的部分。
回答：
这场比赛到底值不值得考虑？

这里必须给判断。
不能只继续罗列信息。
标准结构：
1. 先给总体判断
例如：
如果你希望跑一场赛道有记忆点、赛事成熟，又不只把目标放在成绩上的城市马拉松，厦马很值得放进候选清单。

2. 再给平衡信息
不要只有优点。
例如：
它当然可以跑成绩，但海风、日晒和后程起伏，也意味着比赛当天的体感可能和赛前想象不同。

3. 最后形成 RaceNext 的核心结论
例如：
RaceNext 更愿意把厦马理解成一场“比赛体验本身就很有价值”的马拉松。

判断原则
RaceNext Judgment 必须：
- 有明确结论
- 有证据支撑
- 有正反两面
- 避免绝对化
- 不故意制造争议
- 不为了显得专业而过度判断

六、Core Experiences｜核心体验 / 赛事特点
这一部分回答：
为什么 RaceNext 会形成上面的判断？

建议每场提炼 3 个最有辨识度的核心特点。
原则：
不是罗列所有特点。
而是选最能帮助用户决策的 3 个。
每个特点结构统一：
Item Title
简洁、有信息量。
推荐：
01 / 海，是比赛的一部分

而不是：
01 / 美丽的海滨风光令人难忘

后者太像宣传稿。
Evidence
用 1–2 个自然段说明：
- 跑者怎么反馈
- 媒体怎么描述
- 具体发生在哪里
- 为什么这个体验重要
Conclusion
必要时用一句 RaceNext 结论收尾。
例如：
风景不是比赛之外的背景，而是比赛体验本身的一部分。

七、三个核心特点怎么选
优先从三个不同维度选，不要三个都在讲类似事情。
推荐维度：
1. Why Go｜为什么值得去
例如：
- 景观
- 城市氛围
- 国际赛事感
- 历史感
- 独特路线
2. What’s Hard｜真正难在哪里
例如：
- 爬升
- 海拔
- 天气
- 风
- 路面
- 台阶
- 补给距离
- 后程难度
3. What Makes It Different｜为什么它和别的比赛不一样
例如：
- 比赛 + 旅行
- 城市 + 山地
- 冰川
- 夜景
- 仪式感
- 超强观众氛围
一个好的三段结构应该让用户快速理解：
为什么去 / 有什么坑 / 为什么特别。

八、Runner Fit｜这场比赛适合你吗？
这一部分回答：
我是不是这场赛事的目标跑者？

通常保持 3 条判断。
每条结构：
Item Title
例如：
你希望赛道本身值得记住

一段解释
说明为什么这类用户会喜欢。
不要做成：
- 心理测试
- checkbox
- “符合 2 条就适合你”
- 机械评分系统
RaceNext 是决策辅助，不是测评工具。

九、适配判断的写法
优先写：
你更在意什么。

而不是：
你是什么人。

推荐：
- 你希望赛道本身值得记住
- 你在意成熟的大型赛事体验
- 你能接受比赛日一定的不确定性
避免：
- 你是一个热爱生活的人
- 你是进阶跑者
- 你非常勇敢
- 你追求极致体验
这些没有决策价值。

十、Closing Sentence｜Race Guide 结尾
Race Guide 最后可以有一句轻量 closing。
作用：
从“赛事判断”自然过渡到“住宿决策”。

例如：
如果已经决定去厦门跑一次，接下来最值得提前想清楚的，就是比赛当天住在哪里、怎么去起点。

Closing 不是新模块。
不要：
- 新标题
- 新 eyebrow
- 新 CTA
- 新卡片
它只是把用户自然带到 Accommodation。

十一、正文语言风格
RaceNext 的文字应该是：
像一个真的跑过、看过很多比赛的人，在认真和另一个跑者聊天。
不是：
- 官方新闻稿
- SEO 文章
- 小红书营销文
- AI 百科
- 专业术语堆砌
- 文艺散文
关键词：
- 自然
- 克制
- 有判断
- 有人味
- 专业
- 不端着

十二、正文句子规范
优先：
短句 + 中等长度句子混合。
不要连续很多特别长的复句。
也不要：
一句话。
一个段落。
一句话。
一个段落。
一篇长页面如果大量这样写，会很碎。
推荐：
厦马最鲜明的体验之一，就是海一直离你不远。跑者赛记里经常提到环岛路、演武大桥、海岸线等景观，尤其到了演武大桥，这一段往往也是很多人最容易记住的赛程。

而不是：
厦马最鲜明的体验之一，就是海一直离你不远。
跑者经常提到环岛路。
还有演武大桥。
这一段很特别。

十三、自然段规范
一个自然段通常表达一个完整意思。
建议：
- 每段 2–4 句话
- 一般不要超过 4–5 行视觉高度
- 一个完整语义不要强行拆段
- 不手工 <br>
- 让页面自然换行
长内容可读性的关键不是“多分段”。
而是：
语义完整 + 合理留白。

十四、强调句规范
页面允许有强调。
但不要每段都有“金句”。
需要强调时：
- 保持正文尺寸
- 通过字重强调
- 必要时独立成段
例如：
天气、风和后程体感，值得和配速计划一起考虑。

不要为了强调就：
- 放大字号
- 加颜色
- 加引号
- 做卡片
- 做 quote block

十五、避免重复表达
同一个判断不要在多个模块反复出现。
例如：
如果 Opening 已经讲了：
厦马有旅行感。

RaceNext Judgment 可以讲：
为什么这让它值得考虑。

Core Experience 可以给：
跑者真实反馈证据。

Runner Fit 再讲：
哪类用户会因此喜欢。

而不是四个地方都重复：
厦马很适合跑马 + 旅行。

每个模块承担不同任务。

十六、SEO 撰写原则
SEO 是结果，不是写作目的。
禁止：
2027厦门马拉松是2027厦门马拉松跑者非常关注的一场2027厦门马拉松赛事……

RaceNext 内容应该自然覆盖用户真正关心的问题：
- 这场比赛怎么样
- 难不难
- 风景如何
- 适合 PB 吗
- 适合什么跑者
- 有什么坑
- 住宿怎么选
如果内容真实、有价值，关键词自然会出现。

十七、RaceNext 不写什么
默认不写：
- 低价值 FAQ
- 官方资料的机械复制
- 冗长赛事历史
- 大量无决策价值的数字
- 泛泛“赛事意义”
- “值得所有跑者挑战”
- “一生必跑”
- “绝美赛道”
- “天花板赛事”
- 没有证据支持的夸张词
除非真实来源能够支持，否则不要使用。

十八、内容来源搜集原则
每场赛事正式写作前，建议至少查看三类材料：
1. 官方信息
确认赛事事实。
2. 媒体报道
理解：
- 赛事特点
- 赛道变化
- 组织信息
- 历史背景
3. 真实跑者反馈
重点找：
- 赛记
- 完赛复盘
- 社区帖子
- 视频文字总结
- 多届参赛体验
不要只看一篇文章就得出赛事人格。
优先寻找：
多来源反复出现的共同体验。

十九、来源转化成内容的方法
原始资料可能是：
“35 公里以后逆风很大，演武大桥回来的时候已经被晒麻了。”

RaceNext 不需要照抄。
可以整理成：
有跑者特别提到，比赛后半程再次经过演武大桥时，海风、日晒与已经累积的疲劳会让体感明显变难。

这是：
真实信息 → 组织优化
允许。
但不能增加：
几乎所有跑者都会在这里掉速。

除非数据或大量反馈确实支持。

二十、赛事人格提炼
正式写 Race Guide 前，先用一句话定义赛事人格。
例如：
上海马
跑成绩，也跑上海。
北京马
中国马拉松的仪式感。
厦门马
一场很适合把比赛和城市体验放在一起的海滨马拉松。
HK100
看似离城市很近，真正跑起来一点都不“城市”。
贡嘎100
更像一次用越野跑完成的高山穿越。
这句话是内部内容方向。
不一定直接展示给用户。
它的作用是：
确保整篇内容围绕同一个赛事人格展开。

二十一、内容撰写标准流程
每新增一场赛事，固定按照以下流程：
1. 收集官方事实
2. 收集媒体报道
3. 收集真实跑者反馈
4. 找高频共识
5. 找争议 / 不一致体验
6. 提炼赛事人格
7. 写 Opening
8. 写 RaceNext Judgment
9. 提炼 3 个 Core Experiences
10. 写 Runner Fit
11. 写 Closing
12. 检查是否存在重复
13. 检查是否存在未经支持的事实
14. 检查 RaceNext 判断是否明确标识
15. 最后再做 SEO Title / Description

二十二、最终自检清单
发布前必须逐项检查：
- 赛事事实都有可靠来源吗？
- 有没有把往届信息当成当前届信息？
- 有没有杜撰跑者体验？
- 有没有把单个跑者观点写成普遍共识？
- 有没有把 RaceNext 判断包装成事实？
- Opening 是否快速建立赛事印象？
- Judgment 是否真的给出了判断？
- 三个特点是否互相有区分？
- Runner Fit 是否真的帮助用户判断适配？
- 是否存在明显重复？
- 是否为了 SEO 写了废话？
- 是否有一句话一个段落的问题？
- 是否仍然有人味，而不是百科语言？
只要其中任何一个答案有问题，都应该继续修改。


最后一句原则
RaceNext 不需要成为“信息最多”的赛事网站。
更重要的是成为：
帮跑者更快看懂一场比赛，并做出更好选择的网站。

因此内容的长期壁垒不是赛事资料，而是：
真实信息筛选 + 跑者体验聚合 + RaceNext 判断。
这三个东西，才是 RaceNext 内容真正值得长期积累的资产。
