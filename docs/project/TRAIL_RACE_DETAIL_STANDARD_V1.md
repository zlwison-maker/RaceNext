
RaceNext 越野赛事详情页内容标准 V1

它是在现有《RaceNext 赛事详情页内容撰写规范 V1》基础上的越野赛事补充规范，不替代原有标准，而是新增 Trail Race 专属规则。原有硬规则继续全部适用：真实信息、真实跑者反馈、RaceNext 判断三层分开，不能杜撰。

一、越野赛事与路跑赛事的核心区别
路跑赛事详情页主要解决：
这场比赛值不值得跑？适不适合我？如果决定去，住宿怎么安排？

标准结构：
1. HERO
2. RACE GUIDE
3. ACCOMMODATION
4. NEXT
越野赛事由于决策复杂度更高，除了“选不选这场比赛”，还存在大量比赛执行层面的关键判断，例如：
- 前后半程节奏如何分配
- 爬升集中在哪个阶段
- CP 怎么利用
- 什么时候补给
- 夜间怎么切换状态
- 哪个阶段最容易出现胃口下降
- CP 停留如何控制
- 如何把后半程拆成多个阶段
因此越野赛事增加一个一级内容模块：
1. HERO
2. RACE GUIDE
3. RACE STRATEGY
4. ACCOMMODATION
5. NEXT
越野赛事详情页核心用户路径因此变成：
认识比赛 → 判断比赛 → 理解比赛执行策略 → 解决住宿 → 发现下一场

二、RACE STRATEGY 的定位
一级模块：
RACE STRATEGY
CP 点与补给策略
它不是：
- 官方 CP 表
- 赛事规则页
- 补给清单
- 关门时间表
- Drop Bag 说明
- 专业运动营养处方
它真正解决的问题是：
如果我已经决定参加这场越野赛，在比赛过程中最容易在哪里犯错？我应该如何管理节奏、补给和比赛状态？

内容核心仍然是：真实跑者反馈 + RaceNext 基于这些反馈做出的总结和判断

三、官方 CP 信息与 Race Strategy 必须分开以下信息本质上属于赛事结构化信息：
- CP 名称
- CP 距离
- 累计爬升 / 下降
- 关门时间
- 官方补给内容
- 是否提供热食
- 是否有 Drop Bag
- 医疗服务
- 退赛点
- 下一段距离
这些内容未来统一归入 RaceNext 的赛事信息体系 / Race Graph。
当前 RACE STRATEGY 不重复展示这些官方信息。
这样可以避免页面从“赛事决策内容”突然变成“查表工具”。

四、RACE STRATEGY 的内容来源与 Race Guide 完全一致，继续执行三层内容规则。
1. Official / Event Facts
只用于支撑策略判断，例如：
- 官方明确说明后半程爬升集中
- 某段进入夜间
- 路线包含大量台阶
- 某届赛事线路结构
必须有官方依据。
2. Real Runner Feedback
重点寻找真实跑者关于以下维度的反馈：
节奏
- 前半程是否容易跑快
- 哪个阶段开始明显变难
- 跑者在哪里容易透支
CP
- 如何利用 CP
- 哪些阶段容易停太久
- 是否有人因为无计划停留浪费大量时间
进食
- 前半程如何摄入
- 后半程胃口是否变化
- 甜食疲劳
- 固体 / 液体切换
- 热食体验
补水 / 电解质
- 哪些阶段更容易缺水
- 天气和温度的影响
- 跑者真实出现的问题
夜间
- 入夜后体感变化
- 热食 / 热饮反馈
- 装备与心理变化
胃口
- 吃不下
- 甜食疲劳
- 肠胃不适
- 哪些替代食物更容易接受
CP 停留
- 跑者停留时间
- 换装
- 处理脚部
- 吃热食
- 充电
- Drop Bag
心理策略
- 如何处理最后 20–30km
- 是否把比赛拆成“下一个 CP”
- 哪些方法帮助跑者继续推进

五、RACE STRATEGY 不按 CP1 / CP2 / CP3 机械组织
RaceNext 不应该按照：
CP1 怎么办
CP2 怎么办
CP3 怎么办
CP4 怎么办

逐站写攻略。
原因：
- 页面过重
- 不同年份 CP 容易变化
- 不同组别 CP 不一致
- 维护成本过高
- 用户真正需要的是“比赛阶段判断”
因此应该按照：
比赛状态发生变化的关键阶段来组织。

六、标准建议：3 个关键阶段
大多数长距离越野赛事的 RACE STRATEGY 建议控制在 3 个核心内容项。
不是固定文案，而是固定逻辑。
01 / 前半程
主要回答：
比赛状态最好时，最容易犯什么错？

常见内容：
- 速度过快
- 过于兴奋
- 推迟补给
- 前半程消耗过多
- 因为可跑性强而错误判断赛事难度
RaceNext 判断通常聚焦：
前半程控制强度、建立规律补给，为真正困难的后半程保留能力。

02 / 中段 / 入夜
主要回答：
当比赛从“正常跑步”进入“长时间耐力状态”以后，会发生什么？

常见内容：
- 胃口下降
- 甜味疲劳
- 热食 / 咸味需求
- 身体发冷
- 夜间状态变化
- 爬升增加
- 补给策略需要切换
RaceNext 更关注：
“还能不能持续摄入”比“吃得是否理论最优”更重要。

但这是判断，不是统一营养公式。
03 / 后半程
主要回答：
当剩余距离仍然很长、身体已经疲劳时，如何继续比赛？

常见内容：
- CP 停留效率
- 换装
- 处理脚部
- 补水 / 进食
- 心理拆解
- 最后大爬升
- “只想到下一个 CP”
RaceNext 常见判断：
进入 CP 前知道自己要完成什么；后半程不再管理整场比赛，只管理“下一段”。

七、允许按赛事特点调整三段结构
“前 / 中 / 后”不是死模板。
如果真实资料显示某场赛事最关键的是：
- 高海拔
- 极寒
- 夜间
- 冰川
- 技术下降
- 长距离无补给段
则应该围绕真正的比赛风险调整。
原则始终是：
选择最能影响比赛执行结果的 3 个阶段 / 问题。

不要为了保持统一而牺牲赛事真实性。

八、多组别赛事如何处理
越野赛事经常存在：
- 100K
- 60K
- 50K
- 30K
- 20K
不同组别：
- 路线不同
- CP 不同
- 爬升不同
- 夜间比例不同
- 补给策略不同
RaceNext 不默认给所有组别分别生成 Race Strategy。

九、核心组别原则
每场越野赛事默认只选择 一个核心 / 旗舰组别 做深度策略。
选择标准：
1. 最能代表赛事品牌的组别
2. 用户关注度最高
3. 决策复杂度最高
4. 真实跑者反馈最丰富
5. 有足够资料支持真实内容
例如：
HK100 → 100K 主赛
未来贡嘎100，如果 100K 是核心赛事，则优先围绕 100K。
不要机械规定“永远写最长组”。

十、必须明确 Scope
RACE STRATEGY 标题下面必须有一段轻量说明。
标准逻辑：
以下内容主要基于 XXX 核心组别的路线特点，以及历届完赛跑者的真实赛记与比赛反馈。不同年份的路线、CP 设置和具体补给可能变化，其他组别也可能不同，请以对应届别官方赛事信息为准。

作用是明确：
- 适用哪个组别
- 跑者反馈可能跨届
- CP 会变化
- 不把历史经验包装成当前届官方事实

十一、补给内容不能变成统一处方
禁止直接给所有用户：
- 每小时必须摄入多少克碳水
- 每小时喝多少毫升水
- 必须吃几个胶
- 固定盐丸数量
- 固定 CP 停留分钟数
这些高度依赖：
- 个人体重
- 配速
- 温度
- 出汗率
- 肠胃
- 训练习惯
- 比赛目标
RaceNext 更适合回答：
哪个阶段容易发生什么问题，以及跑者应该提前验证哪些能力。

十二、可以给策略，但要保持决策级别
推荐：
前半程不要因为可跑就推迟进食。

如果训练里只测试了甜味能量胶，长时间比赛前值得验证自己对咸味、固体和热食的接受度。

进入关键 CP 前，先明确自己需要补水、进食、处理装备还是处理脚部。

后半程可以把比赛拆成一个个下一个 CP。

不推荐：
37km CP 必须吃两个胶 + 500ml 电解质。

除非未来 RaceNext 已经具备个体化运动数据和专业策略能力。

十三、CP 停留的内容原则
RaceNext 不给统一“最优停留时间”。
真实跑者之间差异很大：
- 精英跑者可能几十秒或数分钟
- 普通完赛跑者可能需要换装、处理脚、吃热食
- 极端情况下可能需要较长恢复
RaceNext 应该强调：
计划性，而不是绝对速度。

进入 CP 前知道：
- 我要补什么
- 我要换什么
- 我要处理什么
- 下一段需要什么
- 做完就走
重点是避免：
“坐下来以后才开始想自己要干什么。”

十四、夜间策略内容原则
对于进入夜间的长距离赛事，需要主动研究：
- 跑者入夜后的胃口
- 温度变化
- 热饮 / 热食反馈
- 困倦
- 装备切换
- 心理状态
但不能因为“百公里”就默认一定存在这些问题。
仍然必须有真实赛记支持。

十五、Race Strategy 的语言风格
与 Race Guide 一致：
像一个真的跑过、看过很多完赛复盘的人，在和另一个跑者认真讨论比赛。

不要写成：
- 教练课件
- 营养论文
- 官方攻略
- 户外生存指南
- “大神经验”
- 夸张警告
语言应该：
- 专业
- 自然
- 克制
- 实用
- 有判断
- 不装专业

用一段话把整个赛事执行策略压缩总结。

十七、Closing 原则
例如 HK100：
如果把这些真实跑者反馈压缩成几句话，HK100 100K 的比赛策略核心不是记住每个 CP 吃什么，而是：前半程控制速度和规律进食，中段以后保证自己还能持续摄入，入夜后准备好补给切换方案，进入 CP 前知道要完成哪些动作，最后二三十公里只管理“下一个 CP”。

它承担：
把复杂经验重新压缩成可记住的策略。

不要再创造新的内容。

十八、SEO 原则
RACE STRATEGY 可以自然覆盖：
- XXX CP
- XXX 补给
- XXX 越野攻略
- XXX 后半程
- XXX 夜跑
- XXX 100K
- XXX 怎么跑
- XXX 难点
但不能为了关键词专门增加低价值段落。
依然遵循：
用户价值优先，SEO 是自然结果。

二十、最终自检清单
发布越野赛事前额外检查：
- 是否明确 Race Strategy 对应哪个组别？
- 是否错误覆盖了其他组别？
- 是否把历史 CP 当作当前届 CP？
- 是否把跑者个体补给策略写成通用方案？
- 是否存在统一碳水 / 饮水处方？
- 是否有真实赛记支撑胃口、夜间、CP 等描述？
- 是否明确区分跑者反馈与 RaceNext 判断？
- 三个 Strategy Item 是否真正代表比赛不同阶段 / 风险？
- 是否比官方 CP 表更有决策价值？
- 是否仍然保持页面简洁？
- 是否值得用户花时间读？
如果答案是否定的，就不要上线。
最后一条原则
RaceNext 越野赛事详情页不应该成为：
“一张更复杂的赛事资料表。”

它应该帮助跑者回答两个更重要的问题：
这场比赛适不适合我？

以及：
如果我真的去跑，哪些阶段最值得提前想清楚？

这就是越野赛事相比普通路跑赛事，RaceNext 应该提供的额外用户价值。
