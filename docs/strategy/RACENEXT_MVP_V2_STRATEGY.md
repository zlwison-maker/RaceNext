# RaceNext MVP V2 Strategy

Version: 1.0
Status: Active proposal
Last Updated: 2026-07-31

---

# 1. 产品定位

RaceNext 的长期定位不变：

> 跑者的赛事决策顾问。

长期要解决的问题是：

> 基于我的情况，下一场应该跑什么？

这意味着 RaceNext 未来会持续建设：

- 个性化赛事推荐
- AI 赛事决策
- 适合人群分析
- 训练建议
- 参赛规划

但是 MVP V2 阶段的定位调整为：

> 热门赛事参赛服务助手。

MVP V2 一句话：

> 帮助已经决定参加热门赛事的跑者，更高效完成报名、交通、住宿、装备和保险准备。

因此，本阶段不优先验证 AI 决策能力，而是优先验证：

> RaceNext 能否在 3 个月内通过热门赛事服务入口实现月收入 5000 元。

MVP V2 的核心判断标准不是“页面是否足够智能”，而是：

- 是否有搜索流量。
- 是否能承接明确参赛意图。
- 是否能引导用户完成报名前后的消费决策。
- 是否能产生可追踪的联盟收入。

---

# 2. 用户需求分析

## 长期需求

长期用户需求是：

> 我下一场跑什么？

这个问题发生在用户尚未确定赛事之前，用户需要 RaceNext 帮他比较赛事、判断适合度、评估风险和规划参赛节奏。

长期需求对应 Decision Layer 和 Personalized Agent。

## MVP 需求

MVP V2 用户需求是：

> 我已经决定跑这个比赛，接下来怎么办？

这个问题发生在用户已经知道赛事名称、已经有报名意愿，甚至已经报名之后。

用户此时最关心的不是抽象推荐，而是具体执行：

- 怎么报名？
- 报名什么时候截止？
- 去哪里住更方便？
- 怎么到比赛地？
- 需要准备哪些装备？
- 是否需要买保险？
- 是否值得顺路旅行？

## 搜索行为

MVP V2 优先服务有明确赛事意图的搜索行为。

典型搜索词包括：

- 赛事名称 + 报名
- 赛事名称 + 报名时间
- 赛事名称 + 抽签
- 赛事名称 + 住宿
- 赛事名称 + 酒店
- 赛事名称 + 交通
- 赛事名称 + 高铁
- 赛事名称 + 装备
- 赛事名称 + 强制装备
- 赛事名称 + 保险
- 赛事名称 + 攻略

这些搜索词说明用户已经进入参赛准备阶段，商业转化意图更强。

MVP V2 不以泛跑步内容、训练知识、赛事资讯流作为主入口。

# 3. MVP 用户路径

MVP V2 用户路径：

```text
搜索入口
↓
赛事页面
↓
报名信息
↓
参赛准备服务
↓
商业推荐
↓
联盟收入
```

## 核心流量来源

MVP V2 面向中国大陆跑者，核心流量来源是：

- SEO
- 微信搜索
- 公众号

SEO 优先覆盖百度、微信搜索、搜狗、360 等中国大陆用户常用搜索环境。

公众号承担：

- 报名提醒
- 赛事节点提醒
- 攻略分发
- 用户沉淀
- 后续复访

Google Search 不是 MVP V2 核心渠道。

Google 可作为未来服务海外赛事、海外跑者或英文内容时的增长渠道，但不作为当前 3 个月收入验证的主要假设。

## 页面任务

赛事页面在 MVP V2 中的核心任务不是“解释为什么适合你”，而是：

- 承接赛事名称搜索。
- 提供准确报名入口和报名状态。
- 给出参赛准备清单。
- 把住宿、交通、装备、保险、旅行等高意图需求连接到服务入口。
- 记录用户点击行为，为后续商业优化和决策产品升级提供数据。

# 4. MVP 商业模式

MVP V2 的主要收入来源：

> 联盟佣金。

商业模块不是后置增强项，而是 MVP V2 核心。

没有商业转化入口的赛事页面，不完整。

## 酒店

适用场景：

- 外地参赛。
- 热门城市马拉松。
- 越野赛事举办地周边住宿稀缺。
- 赛事起终点附近住宿需求强。

潜在合作和联盟来源：

- 携程
- 飞猪
- 美团等

页面应优先呈现：

- 推荐住宿区域
- 距离起点 / 终点 / 领物点
- 价格区间
- 预订入口

## 交通

适用场景：

- 异地参赛。
- 山地、县城、景区、度假区等交通不便赛事。
- 高铁站、机场到比赛地有明显接驳需求。

商业方向包括：

- 火车票
- 租车
- 接送服务
- 本地包车或拼车信息

页面应优先帮助用户判断：

- 到达方式
- 推荐交通路径
- 关键距离
- 是否需要提前安排接驳

## 装备

适用场景：

- 越野赛强制装备。
- 高海拔、高寒、夜间、长距离赛事。
- 雨季、山地、沙漠、冰雪等特殊环境赛事。
- 马拉松补给、能量胶、防晒、压缩装备等常规消费。

潜在合作和联盟来源：

- 淘宝联盟
- 京东联盟

页面应区分：

- 必备装备
- 推荐装备
- 可选装备

## 保险

适用场景：

- 越野跑。
- 高海拔赛事。
- 长距离赛事。
- 异地参赛。
- 海外参赛。

商业方向：

- 户外运动保险
- 短期意外险
- 高风险运动扩展保障

页面应明确提醒用户：

- 保险类型
- 保障边界
- 是否覆盖越野跑 / 马拉松 / 高海拔 / 赛事活动

## 周边旅行

适用场景：

- 文旅型马拉松。
- 景区越野赛。
- 适合家庭同行的赛事。
- 外地用户需要安排 2-3 天行程。

商业方向：

- 景点门票
- 本地旅行服务
- 餐饮和短途游

# 5. MVP 与长期产品关系

MVP V2 是 RaceNext 长期愿景的商业入口验证，不是对长期方向的否定。

MVP V2 做的是：

> 赛事消费入口。

未来长期产品做的是：

> 赛事决策 Agent。

MVP V2 通过热门赛事页面积累：

- 用户搜索数据
- 用户点击行为
- 赛事数据
- 消费偏好
- 不同赛事类型的商业转化表现
- 报名、住宿、交通、装备、保险等需求的真实优先级

这些数据未来会反哺：

- 个性化推荐
- AI 赛事决策
- 适合人群分析
- 训练建议
- 参赛规划

长期架构方向：

```text
Race Event Data
↓
Monetization Layer
↓
Decision Layer
↓
Personalized Agent
```

阶段原则：

- MVP V2 优先建设 Monetization Layer。
- Decision Layer 保留为长期能力，但不作为当前收入验证的前置条件。
- Personalized Agent 属于未来产品阶段，不进入当前 MVP 开发范围。

# 6. MVP V2 成功标准

MVP V2 的核心成功标准：

> 3 个月内实现月收入 5000 元。

过程指标：

- First20 Monetization Events 页面上线。
- 每个上线赛事至少有报名、住宿、交通、装备、保险中的 2-3 类服务入口。
- 重点赛事能覆盖“赛事名称 + 报名 / 住宿 / 交通 / 装备 / 保险”等搜索意图。
- 联盟链接点击可追踪。
- 每周复盘赛事页面流量、点击率、转化收入。

本阶段不以 AI 适合度准确率、推荐算法效果、用户画像完整度作为主要成功指标。
